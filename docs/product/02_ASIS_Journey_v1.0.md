## 2. 证据覆盖说明

### 真实行为覆盖较强

- P01：收到任务、形成约束、跨工具、导入下游、打印失败和返工；
- P03：口头目的、实际测量、建模、切片、制作设置、打印验证和返工。

### 情境覆盖

- P02：信息收集、说明卡约束、AI使用、设计工具链、交付前检查与工厂交付设想；
- P02不能证明该工作流已实际执行，也不能证明工厂或xTool Studio会接受其设想产物。

## 3. 旅程中的关键断点

1. **范围断点**：用户尚未确认最终交付物就开始收集或设计；
2. **状态断点**：暂定约束被当成最终值；
3. **上下文断点**：跨工具需要重新输入或检查信息；
4. **阶段断点**：上游文件问题到下游才暴露；
5. **责任断点**：用户不清楚问题由设计者、Studio操作人员还是设备侧处理；
6. **验证断点**：文件可导入被误解为生产就绪；
7. **恢复断点**：失败后缺少明确返回位置和复检条件。

其中1—7均为`[研究者推断]`对证据的旅程化归纳。

## 4. 当前不能确认

- 各阶段实际耗时和发生频率；
- 说明卡真实印刷和加工流程；
- SVG错误在目标用户中的具体频率；
- xTool Studio真实导入与设置路径 `[待实际验证]`；
- MakerFlow机会是否会减少返工；
- 用户是否愿意在每个阶段维护项目记录。
