# 方案C｜纯口头直接提问式任务访谈 v1.0

> 适用对象：设计学生、初级创作者、做过课程作业但没有完整制作经验的人。  
> 执行方式：只问问题，不要求打开软件、不要求现场制作。  
> 建议时长：25—30分钟。  
> 研究目标：理解受访者怎样从模糊任务进入信息整理、设计、检查和交付。  
> 原则：一次只问一个问题；先让受访者自由回答，答不出时再给中性提示。

## 0. 开场词

```text
谢谢你接受这次访谈。

我正在研究设计学生或初级创作者，怎样把一个想法逐步变成
可以交给设计软件、制作软件或工厂的文件。

这不是考试，也不要求你熟悉xTool、激光切割或专业生产流程。
没有标准答案，我只想知道按你的真实习惯会怎么处理。

接下来我会给你一个具体任务，再按步骤问你。
你不用一次把流程想完整，我会一段一段问。
不确定时可以直接说“不知道”。
```

## 1. 任务情境

```text
MomoRay是一款可以增加或减少垫片来调节高度的模块化枕头。

现在需要制作一张放在包装内的说明卡，
让用户知道产品结构、如何调节高度，以及仰睡和侧睡时如何调整。

目前还没有确定说明卡尺寸、折页形式、纸张、颜色、字体和最终排版。
最后需要形成可以交给工厂或后续制作流程的文件。
```

## 2. 第一部分｜如何理解任务

1. **[P0]** 你认为最后需要做出来的具体东西是什么？
2. **[P0]** 你现在已经知道哪些信息？
3. **[P0]** 你觉得还缺少哪些信息？
4. **[P0]** 这些缺失信息里，哪三项不确认就很难继续？
5. **[P1]** 哪些信息可以暂时假设，先做一个初稿？

答得太宽时追问：

```text
假如只能确定一个主要交付物，你会选什么？
```

卡住时提示：

```text
可以从内容、尺寸、材料、颜色、包装和制作方式里想。
```

## 3. 第二部分｜先收集什么

6. **[P0]** 拿到任务后，你第一步会做什么？
7. **[P0]** 你会去哪里找资料或参考？
8. **[P0]** 你看同类产品时，主要想获得什么信息？
9. **[P0]** 看到竞品说明书后，怎样判断哪些可以参考，哪些不能照搬？
10. **[P0]** 产品真实信息不完整时，你会向谁确认？
11. **[P0]** 哪些内容绝对不能让AI自己编？

## 4. 第三部分｜如何整理内容

12. **[P0]** 你会怎样决定说明卡必须写哪些内容？
13. **[P0]** 如果信息很多，你会怎样决定先后顺序？
14. **[P0]** 你会把零散内容整理在哪里？
15. **[P1]** 你希望系统把信息整理成什么形式，才方便继续设计？
16. **[P0]** 如果系统先生成一份可以修改的需求和内容清单，你愿意使用吗？为什么？
17. **[P0]** 这份清单里必须有哪些字段，哪些字段会显得太麻烦？

卡住时提示：

```text
例如清单、表格、内容结构、待确认项，或者其他形式。
```

## 5. 第四部分｜尺寸、材料、颜色和形式

18. **[P0]** 你会根据什么决定单页、卡片还是折页？
19. **[P0]** 你会根据什么决定成品尺寸？
20. **[P0]** 包装内部尺寸还不知道时，你会怎么办？
21. **[P0]** 你会根据什么选择纸张或其他材料？
22. **[P0]** 颜色主要应该依据品牌、印刷效果、产品本身，还是其他因素？
23. **[P0]** 字号、信息层级和可读性会怎样决定？
24. **[P1]** 如果系统给出三套候选方案，并写明优点、限制和适用条件，你愿意看吗？
25. **[P1]** 形式、尺寸、材料、颜色、版式、制作方式和输出格式中，哪些建议最有价值？
26. **[P0]** 哪些建议AI只能提供候选，最终必须由人决定？

## 6. 第五部分｜使用哪些工具

27. **[P0]** 从开始到交付，你预计会依次使用哪些工具？
28. **[P0]** AI在这条流程里负责什么?
29. **[P0]** Figma、Illustrator、建模软件或其他工具分别负责什么？
30. **[P0]** 工具之间切换时，哪些内容需要重新复制、输入或制作？
31. **[P1]** 哪一次工具切换最容易出错或返工？

每提到一个工具都追问：

```text
它输入什么？
它输出什么？
为什么要换到下一个工具？
```

## 7. 第六部分｜交付前检查

32. **[P0]** 在把文件交给工厂或制作软件前，你会检查什么？
33. **[P0]** 你会怎样确认文字、尺寸、字体、图片、颜色、格式和路径正确？
34. **[P0]** 如果文件能正常打开，你会认为它已经可以制作了吗？为什么？
35. **[P0]** 文件打不开、尺寸不明确、重要文案缺失、字体或图片丢失、产品事实没确认、路径或刀线有问题中，哪些必须在交付前解决？
36. **[P0]** 上面哪些需要回到原来的设计软件修改？

## 8. 第七部分｜进入制作环境后

引导词：

```text
接下来不要求你懂具体制作软件。
只需要判断：这些事情是否可以等文件交出去以后再处理。
```

37. **[P0]** 选择真实设备、确认纸张或材料、设置加工参数、调整画布位置、查看制作预览、试切或打样中，哪些可以在制作环节处理？
38. **[P0]** 哪些虽然可以稍后处理，但最终制作前必须阻止继续？
39. **[P0]** 如果尺寸在导入后不对，你会先检查源文件还是制作软件设置？为什么？
40. **[P1]** 你希望系统直接修复问题，还是告诉你“去哪个软件、改什么、改完再检查”？为什么？

## 9. 第八部分｜交给工厂

41. **[P0]** 你最终会交给工厂哪些文件？
42. **[P0]** 除了文件，还需要向工厂说明什么？
43. **[P0]** 你怎样确认工厂理解了要求？
44. **[P0]** 工厂把文件退回来时，最可能是什么原因？
45. **[P0]** 收到修改意见后，你会回到哪个工具处理？
46. **[P0]** 谁负责最终确认文件可以制作？

卡住时提示：

```text
可以考虑尺寸、材料、颜色、折页、数量和待确认问题。
```

## 10. 第九部分｜AI与人工边界

47. **[P0]** 哪些事情你愿意让AI直接完成？
48. **[P0]** 哪些事情AI可以建议，但必须由你确认？
49. **[P0]** 哪些事情完全不能让AI自己决定？
50. **[P0]** AI给建议时，必须同时说明什么，你才愿意相信？
51. **[P0]** 假如AI建议与你的经验不同，你会根据什么接受或拒绝？

卡住时提示：

```text
依据、优点、缺点、风险、置信度、是否需要确认。
```

## 11. 收尾

52. **[P0]** 整个流程中最麻烦的是哪一步？
53. **[P0]** 最容易返工的是哪一步？
54. **[P0]** 最希望有人或系统帮你完成什么？
55. **[P0]** 最需要你亲自确认的是什么？
56. **[P1]** 有没有哪一步我没问到，但你觉得很重要？

## 12. 主持人快速追问句

```text
为什么？
具体会怎么做？
能举一个类似作业的例子吗？
这一步发生在哪个工具之前或之后？
你会把什么交给下一个人或软件？
如果不知道这个信息，你会继续还是暂停？
谁负责最后确认？
```

## 13. 不要这样问

```text
你是不是需要Creative Brief？
你觉得SVG Checker有用吗？
你是不是应该先确认尺寸？
这个问题应该在Studio里解决吧？
MakerFlow这样设计是不是很好？
```

## 14. 20分钟精简版

只问：

```text

P0-06、08、11
P0-12、16
P0-18、19、21、26
P0-27、30
P0-32、34、35、37、38
P0-41、42、46
P0-48、49、50
P0-52、53、54
```

共约25个直接问题。

## 15. 最低有效记录

每次访谈至少获得：

1. 一个明确交付物；
2. 三项缺失约束；
3. 一条工具链；
4. 两项需要重复输入的内容；
5. 三项交付前问题；
6. 三项制作环境内问题；
7. 一项AI可建议内容；
8. 一项必须人工确认内容；
9. 三条受访者原话。
