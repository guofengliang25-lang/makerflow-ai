# V3-W2-D03｜访谈补充提问与过程重建任务 v1.1

> 适用情况：受访者不是专业制造人员，没有使用过 xTool Studio，无法在访谈现场完整操作软件，但做过课程作业、建模、打印、包装、设计输出或相近制作任务。  
> 研究目标：还原其真实决策和工具链，而不是要求受访者像产品经理一样提出完整方案。

## 1. 样本有效性边界

### 可以支持

- 初级设计学生如何理解制作任务；
- 如何补充用途、尺寸、材料、颜色、版式和内容；
- 如何在 AI、绘图、建模、排版和制作方之间切换；
- 信息如何在工具切换时遗漏或重新整理；
- 哪些错误在下游软件或制作阶段才暴露；
- 哪些决策愿意接受 AI 建议；
- 哪些决策必须人工确认；
- 是否需要可编辑 Brief、问题检查和明确 Next Step。

### 不能直接支持

- xTool Studio 的具体交互是否好用；
- xTool Studio 是否已具备某项 Checker 能力；
- 激光切割用户一定存在同样的问题；
- SVG Checker 的每条规则都是真实高频需求；
- MakerFlow 已经能够降低返工；
- 所有初级 Maker 都采用相同工具链。

### 样本标记建议

```text
样本类型：邻近目标用户
经验类型：设计课程作业 + CAD/SU建模 + 拓竹3D打印
可支持：跨工具、约束决策、文件交接、下游报错和人工确认
不可支持：xTool Studio专项结论、激光切割专项结论
```

## 2. 方法调整

原“任务观察”改为：

> Guided Process Reconstruction｜引导式过程重建

受访者不需要现场完成设计，也不需要像产品经理一样想全流程。主持人通过时间线、工具卡、约束卡、文件卡和问题分类卡，帮助其逐步还原“当时会怎么做”。

## 3. 过程重建任务

### 情境

```text
现在假设你需要为 MomoRay 模块化枕头制作一张包装内折页说明卡。

需要解释：
1. 如何增加或减少垫片；
2. 仰睡和侧睡调整建议；
3. 产品结构和调整步骤。

目前还没有确定：
- 具体尺寸；
- 折页形式；
- 纸张；
- 颜色；
- 字体；
- 最终排版；
- 由谁印刷或裁切。

请不用一次想完整。
我们会按“收到任务—整理内容—设计—检查—交付”的顺序慢慢走。
```

## 4. 收到任务

### P0

1. 收到任务后第一件会做什么？收集信息
2. 会先找资料，还是先画草图？为什么？先找资料
3. 会去哪里找同类产品或参考？信息网站和购物网站
4. 希望从参考中获得什么？人家信息如何排版、尺寸大小、材料和展现形式、跟产品包装配合与创新
5. 哪些信息必须先找到，才能继续？尺寸最大最小范围、卡片信息量承载多少

### 卡住时可展示

```text
可能需要考虑：
- 用户需要知道什么；
- 产品有哪些真实信息；
- 同类说明书怎样组织；
- 包装内部有多大空间；
- 最终由谁制作。
```

追问：

- 哪些是你主动想到的？
- 哪些是看到提示后才想到的？

## 5. 整理内容

### P0

1. 怎样判断说明书里应该放哪些内容？根据已有的产品和法律规范，
2. 从小红书、淘宝或现实产品中看到的内容，会全部照搬吗？不会
3. 怎样判断哪些适合自己的产品？根据产品的说明材料和材料的相似度
4. 产品事实不完整时，会向谁确认？团队的设计师
5. 会怎样把零散信息整理成可设计的内容？找参考

### 结构刺激卡

```text
目标用户 / 使用场景 / 必须说明的信息 / 产品真实参数 /
操作步骤 / 注意事项 / 品牌语气 / 待确认内容
```

追问：

- 哪几项必须先确认？必须说明的信息、操作步骤
- 哪几项可以边设计边补？品牌语气、使用场景
- 哪几项绝对不能让 AI 自己编？目标用户、使用场景、产品真实参数、操作步骤

## 6. 获得设计建议

### P0

1. 会把什么内容给 AI？已经确定的内容去调整内容的排版、语气和表达规范
2. 希望 AI 返回什么？
3. AI给出图案、颜色或版式建议后，如何判断能不能用？经验
4. 会直接采用，还是只当灵感？灵感
5. 通常会反复问 AI 什么？可行性和风格，去做思维发散
6. 哪些建议必须显示依据、优点和限制？材质、印刷方式、表达规范

### 建议类型卡

```text
形式 / 尺寸 / 材料 / 颜色 / 版式 / 图案 / 制作路径 / 输出格式
```

让受访者分类：

- 很有帮助；
- 可以参考；
- 不需要；
- 必须人工确认。

## 7. 设计与工具选择

### P0

1. 会先在哪个软件开始？figma
2. 为什么用它，而不是另一个？前期对信息采集、低保真比较好、团队沟通
3. AI灵感如何进入绘图软件？当图片来参考
4. 绘图结果如何进入 Figma 或排版软件？直接插入
5. 哪些内容需要重新输入或重新制作？具体信息内容
6. 工具切换时最容易遗漏什么？没有

### 时间线

```text
找参考
→ ________
→ ________
→ ________
→ 交付工厂
```

每个节点追问：

- 输入是什么？
- 输出是什么？
- 为什么切换？
- 哪些信息没有跟过去？
- 哪一步可能返工？

## 8. 尺寸、材料、颜色和版式

### P0

1. 尺寸应该根据什么决定？
2. 包装空间不知道时怎么处理？多方案呈现（万能和特定）
3. 材料应该由谁决定？
4. 颜色依据品牌、印刷还是个人审美？品牌
5. 最小字号和可读性怎么判断？按照现有设计规范
6. 哪些可先用临时值？大致尺寸
7. 哪些不确认就不能交付？必须有的信息和尺寸

### 选择刺激

```text
A. 一个推荐答案
B. 三个候选方案及优缺点
C. 只提醒缺少信息
```

追问：更希望哪一种？为什么？

## 9. 文件检查与问题路由

### P0

1. 交给工厂前会检查什么？配色和字体有没有问题、格式问题、尺寸精准
2. 如何知道文件尺寸正确？反复确认
3. 会检查文字、图片、路径和格式吗？会
4. 哪些必须回原设计软件修？文字内容出错
5. 哪些可由工厂或制作软件处理？尺寸（等比列）
6. 工厂退回文件，最可能是什么原因？
7. 修复后是否需要重新检查？

### A组｜交付前必须解决

- 文件打不开；
- 尺寸不明确；
- 重要文案缺失；
- 字体或图片丢失；
- 路径未闭合；
- 产品事实未确认。

### B组｜进入制作环境后解决

- 选择真实设备；
- 确认纸张或材料；
- 设置加工参数；
- 调整画布位置；
- Preview；
- Framing或试切。

追问：

- 是否同意这个分类？
- 哪些项目应该移动？
- 哪些问题即使可以进入制作软件，也必须在最终制作前阻止继续？

## 10. 交付工厂

### P0

1. 会交给工厂哪些文件？
2. 除了文件，还需要说明什么？
3. 工厂不知道设计目标，会造成什么问题？
4. 怎样确认工厂理解尺寸、材料、颜色和折页方式？
5. 工厂返回修改意见时，会回到哪个软件？
6. 谁负责最终确认？

### 交付物刺激

```text
印刷PDF / SVG或刀线 / 尺寸说明 / 材料方向 /
颜色说明 / 折页示意 / 待确认问题
```

让受访者分类：必须 / 有帮助 / 不需要 / 不确定。

## 11. 失败与回退

### P0

1. 排版完成后才发现尺寸不对，会从哪里重新开始？
2. 工厂说字体或图片有问题，会在哪个工具修？
3. AI给的图案不适合印刷，怎样判断？
4. 哪一步的错误会导致前面全部重做？
5. 希望系统在哪一步提前提醒？

## 12. 主持人引导规则

### 可以

- “我们先只讨论第一步。”
- “先不考虑后面制作，你拿到任务时会做什么？”
- “这里没有标准答案，请按你平时的方式说。”
- “这个信息是你主动想到的，还是看到提示才想到的？”
- “当时如果不知道，你会继续还是暂停？”
- “你能举一个类似作业里的例子吗？”
- “你说交给工厂，具体交什么？”

### 不要

- “正确流程应该是……”
- “你是不是需要Creative Brief？”
- “Checker可以解决这个问题。”
- “这里应该使用SVG。”
- “你应该在Studio内解决。”
- “MakerFlow以后会帮你做。”

## 13. 证据标签

| 标签 | 含义 |
|---|---|
| REAL | 真实做过 |
| RECALL | 对过去经历的回忆 |
| SCENARIO | 对假设任务的回答 |
| PROMPTED | 看到提示后才想到 |
| SPONTANEOUS | 未提示主动提出 |
| INFERENCE | 研究者推断 |

## 14. 单次最低完成标准

- 一条完整工具链；
- 三项主动发现的缺失约束；
- 一次真实或情境返工点；
- 一组导入前问题；
- 一组制作环境内问题；
- 至少三条高价值原话；
- 一项不愿交给AI的决定；
- 一项希望AI提供的建议。

不要求受访者完成：

- 完整产品方案；
- 专业产品需求文档；
- xTool Studio专项分析；
- 所有SVG规则；
- MakerFlow功能设计。
