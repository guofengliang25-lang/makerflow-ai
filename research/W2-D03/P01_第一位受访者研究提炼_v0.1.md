# P01｜第一位受访者研究提炼 v0.1

> 来源：方案A真实经历访谈  
> 样本类型：邻近目标用户  
> 经验：设计课程作业、CAD、SketchUp、拓竹3D打印和小组协作  
> 注意：以下仅基于当前访谈回答，不代表完整用户群体。

## 1. 数据是否有效

### 有效

该受访者没有使用 xTool Studio，但其经历与 MakerFlow 的广义研究问题相关：

- 从模糊任务进入方案；
- 确定尺寸和材料；
- CAD → SU → 切片软件的工具切换；
- 文件格式转换；
- 下游软件发现上游错误；
- 3D打印失败和返工；
- 人工审核；
- AI建议与人工确认边界。

### 不能支持

- xTool Studio具体功能；
- SVG Checker所有规则；
- 激光切割用户行为；
- MakerFlow已经有效；
- 所有设计学生具有相同需求。

## 2. 已观察到的真实流程

```text
老师下发宽泛任务
→ 场地分析与案例参考
→ 小组分别画草图并讨论
→ 确定空间方案
→ CAD平面制图
→ SketchUp建模
→ 导出STL
→ 拓竹软件切片
→ 导出3MF
→ 3D打印
→ 发现失败后返回上游修改
```

## 3. P0发现

### F01｜约束在过程中逐步暴露

证据：

- 场地尺寸、桌椅大小和流动空间在设计过程中不确定；
- 最终模型尺寸需要压缩到3D打印机可容纳范围。

初步判断：

> 用户并非一开始就拥有完整约束，而是在设计和设备限制中逐步补齐。

严重度：S2  
研究优先级：P1（当前单一样本）

### F02｜跨工具转换造成信息损失与后置报错

证据：

- CAD → SU → 拓竹软件；
- 导入下一个软件后发现上一步有问题；
- 存在格式无法接收、导入导出不同步；
- 图中遗漏部分方案内容。

初步判断：

> 文件能够传递，但方案意图、几何完整性和格式兼容性没有自动连续保留。

严重度：S3  
研究优先级：P1

### F03｜部分问题必须在上游解决

证据：

- 比例尺和各部分尺寸关系必须提前正确；
- SU破面、未封面和CAD空隙会导致后续报错或打印失败。

初步判断：

> 几何完整性和关键尺寸属于进入制作前必须解决的问题。

严重度：S3  
研究优先级：P1

### F04｜部分问题在制作环境才暴露

证据：

- 拆解面不成功导致打印报错；
- 打印时出现“炒面”；
- 部件打印成功率不高。

初步判断：

> 文件检查不能覆盖所有设备和加工问题，制作软件和实物阶段仍需独立检查。

严重度：S3  
研究优先级：P1

### F05｜人工审核承担语义和布局判断

证据：

- 老师在辅导课中纠正座椅朝向墙角等布局问题；
- 用户认为方案方向、尺寸细节和每一步最终结果必须人工确认。

初步判断：

> Checker适合确定性文件规则，但空间合理性、方案方向和设计质量仍需人判断。

严重度：S2  
研究优先级：P1

### F06｜AI更适合作为建议与检查辅助

受访者希望AI：

- 检查模型是否封面；
- 提醒是否保存；
- 提醒整体问题；
- 建议导出格式。

不愿交给AI：

- 方案最终方向；
- 每一步最终完成状态；
- 尺寸细节确认。

初步判断：

> AI可提供候选建议和Next Step，但高影响方案和尺寸仍需人工确认。

研究优先级：P1

## 4. 对MakerFlow假设的影响

| 假设 | 当前结果 | 说明 |
|---|---|---|
| 需要Editable Creative Brief | 部分支持 | 任务初始宽泛，约束逐步暴露，但尚未直接测试Brief |
| 需要Constraint Recommendations | 部分支持 | 尺寸、材料和格式选择存在判断需求 |
| 需要Pre-import Checker | 支持 | 比例、空隙、破面、未封面属于上游阻塞问题 |
| 需要Studio/制作环境Checklist | 支持 | 切片、部件成功率和打印失败只能在后续暴露 |
| 需要上下文追踪 | 部分支持 | 方案内容在绘图和协作中有遗漏 |
| AI不能自动决定高风险事项 | 支持 | 方案方向和尺寸细节需人工确认 |

## 5. 当前不能确认

- 用户是否愿意正式填写Creative Brief；
- Brief是否会减少其返工；
- SVG文字、位图和路径规则是否高频；
- xTool Studio内具体应处理哪些问题；
- 材料、颜色和版式建议的接受程度；
- 工厂交付场景中的真实文件问题。

## 6. 建议补访问题

1. 当老师下发宽泛任务后，如果有一张可编辑需求表，你愿意填写吗？
2. 需求表中哪些字段会帮助你，哪些会增加负担？
3. CAD进入SU之前，你希望系统检查什么？
4. 哪些问题必须阻止导出？
5. 哪些问题可以进入切片软件后再解决？
6. 对尺寸、材料、颜色和格式建议，你希望看到一个答案还是多个候选？
7. AI建议需要显示什么依据，你才会相信？
8. 如果系统保存“原始方案—修改原因—最终确认”，对小组协作是否有帮助？

## 7. 记录修正建议

原记录中：

> “可见人工审核仍是发现微观布局瑕疵的关键防线”

这一句是研究者分析，不是受访者原话，应移动到“研究者解释”。

建议拆成：

### 用户事实

> 老师在辅导课中指出休闲座椅朝向墙角等布局问题。

### 研究者解释

> 当前工具没有自动识别该空间布局问题，人工审核承担语义和合理性判断。

## 8. 样本结论

这是一份有效的邻近用户样本。

它最有价值的不是证明 xTool Studio 存在问题，而是证明：

> 初级设计学生的实体制作流程天然跨越多个工具；部分约束在过程中才暴露，部分文件问题必须回上游修复，另一些加工问题只能在切片或设备阶段发现。

后续应继续寻找不同制作路径的样本进行对照，而不是要求所有受访者都使用 xTool Studio。
