| 判断 | 判断依据 | 影响的产品决策 | 置信度 |

## 5. 本周新理解

1. AI 产品项目不只是设计界面，还要定义输入、输出、状态、工具、失败和证据。
2. “计划验证”“软件验证”“真实加工”和“业务上线”是不同状态。
3. API 调用受到代码、环境、认证、计费和模型权限共同影响。
4. 出现错误不代表学习失败；能够定位 401 和 429 本身也是技术基线证据。
5. 一个自证物应与产品主任务一致，而不是为了展示技术强行选择不相关的加工形式。
6. 真实经历和新建 AI 系统必须分开表述。

## 6. 被修正的旧认知

- **原认知**：只要拥有 ChatGPT Plus 和 API Key，就能直接调用 OpenAI API。  
  **新认知**：ChatGPT 订阅与 API Billing 独立；有效 Key 仍需要可用 API 额度。  
  **修正依据**：实际经历 401 `invalid_api_key` 和 429 `insufficient_quota`。

- **原认知**：MakerFlow 的自证物必须是激光切割实体，才能证明数字内容进入机器流程。  
  **新认知**：纸张说明卡更符合真实业务；可以把印刷 PDF、SVG 刀线、软件导入和可选设备加工分层验证。  
  **修正依据**：自证物与 MomoRay 场景、文件格式和现阶段设备条件的匹配分析。

- **原认知**：验证路径要等产品完成后再写。  
  **新认知**：验证路径应在开发前先定义，否则容易做出无法举证或无法验收的功能。  
  **修正依据**：Brief、Checker 和软件交接需要提前定义通过标准。

## 10. 可用于作品集的内容

- **问题定义**：初级 Maker 从模糊创意进入可制作文件时，可能缺少约束澄清和文件检查。
- **关键取舍**：
  - 不做泛 AI 出图；
  - Checker 并入主项目；
  - 选择真实业务相关的包装说明卡；
  - 将印刷、软件和设备验证分层。
- **验证设计**：需求澄清、Creative Brief、SVG Checker、xTool Studio 导入。
- **当前已有证据**：Brief、事实边界、自证物决策、API 错误排查。
- **仍需补齐**：用户研究、竞品研究、真实 SVG 测试、软件导入、真实模型日志。

## 11. 可用于面试的内容

- **情境**：为了转向 Agent/AIGC 产品岗位，我规划 MakerFlow AI 作为技术旗舰项目。
- **任务**：在 API 和设备条件不完整的情况下，锁定一个真实、可验证、不会夸大的项目范围。
- **行动**：
  1. 建立项目组合和事实边界；
  2. 定义目标用户、主任务和非目标；
  3. 将 Checker 定位为内部 Tool；
  4. 将包装说明卡拆成 Print PDF、SVG 和检查报告；
  5. 对 API 的 SDK、401 和 429 问题进行排查；
  6. 设计软件、模型和设备分层验证路径。
- **当前结果**：形成 Brief v1.0、自证物选择表 v1.0 和验证计划；真实 API 调用仍受 Billing 阻塞。
- **反思**：项目可信度来自边界和证据，不来自把计划写成已完成；外部阻塞发生时，应调整依赖而不是伪造验证。

## 12. Stop / Start / Continue

### Stop｜停止

- 停止把“AI生成视觉”视为完整 Agent 产品；
- 停止在未测试前写“提升效率、减少返工”；
- 停止将 Mock、软件导入和真实加工混为一谈；
- 停止因单一 API 阻塞而暂停所有产品工作。

### Start｜开始

- 开始使用统一研究卡分析创作到制作工作流；
- 开始收集官方截图和链接；
- 开始招募目标用户；
- 开始为每项判断保存证据编号；
- 开始以“假设—证据—决策”方式写文档。

### Continue｜继续

- 继续严格区分事实、计划、Mock 和真实结果；
- 继续围绕一个主任务控制 MVP；
- 继续记录失败、限制和修复；
- 继续使用 MomoRay 真实业务背景增强项目可信度。

## 15. 本周总结

W1 的主要成果不是完成了一个 Agent，而是把 MakerFlow 从模糊想法收敛为一个有明确用户、主任务、自证物、非目标和验证路径的个人 Demo。API 真实调用因 Billing 阻塞，但实际排查过程让我理解了环境、认证和额度是模型调用的一部分。我没有用 Mock 冒充真实结果，而是调整依赖，先推进不依赖 API 的研究、产品判断和确定性工具。W2 将重点验证用户问题是否真实，以及 MakerFlow 相比现有创作和制作工具是否存在合理切入点。
